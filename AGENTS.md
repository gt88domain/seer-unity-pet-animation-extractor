# AGENTS.md

## Repo overview

Two parts, no build step, no linter, no CI:

1. **HTML5 game** (`game/`) — 《赛尔传说·星辰冒险》, a Pokémon-like game combining:
   - battle/stat/exp formulas + data (`spt.xml`, `skills.xml`) from `Seer-golang-` (ported to `game/js/engine.js`, trimmed data in `game/data/`),
   - pet art (`body/`/`head/` sprites, type badges) from `seer-unity-assets-` (vendored subset in `game/assets/`),
   - mesh-animated bosses (雷伊 70 / 神秘 4913 / 鲁尔蒂尼 431 / 朵拉格 502) rendered live via `game/js/meshplayer.js`, loading `../<id>.pet.json` + atlas from repo root. New bundles convert via `tools/mesh/export_mesh.py` (UnityPy, pruned to Vertices/UVs + 2048 atlas).
   - post-game secret rotation: `m6.secret` + `m6.secretPlus` (5 bosses), progress in `Game.secretDone[]`; Ghibli Q-pet skin (`game/assets/skins/ghibli/`, manifest-driven, 🎨 toggle).
2. **Extractor** (root) — `index.py` reads a `.pet.json` asset + a `._Atlas_.png` texture atlas, renders mesh deformations per frame, and exports GIF/WebP/PNG frames. `index.html` provides a browser-based WebGL preview of the same data.

## Game layout (`game/`)

- `index.html`, `css/style.css` — shell + all UI styling (classic scripts, no modules; serve repo root over HTTP).
- `js/engine.js` — pure-logic battle engine (port of battle.go/pets.go/skills + full SideEffect impl). DOM-free, `module.exports` for node.
- `js/{audio,sprites,vfx,meshplayer,world,battle,ui,main}.js` — synth SFX/BGM, asset loader, particles, WebGL mesh player, tile maps, battle scene, panels, boot/save/loop.
- `data/{pets,skills}.json` — generated by `tools/build_data.py` from Seer-golang- XML (73 pets, 319 skills; EVO_PATCH/CATCH_OVR/SYNTH overrides in-script, 4913 runtime-injected in main.js).
- `data/game.json` — hand-authored maps (ASCII tiles)/wild tables/bosses/secretPlus/items/shops/text (levelCap 100).
- `assets/` — vendored sprites (146 pet PNGs + type badges); `assets/skins/ghibli/` — AI Q-style reskins (manifest.json ids; chromakey via `tools/skins/chromakey.py`).

## Running the tool

```bash
# Default: renders "standby" sequence as GIF to output/
python index.py 4913.pet.json 4913._Atlas_.png

# Export WebP with transparent background
python index.py 4913.pet.json 4913._Atlas_.png --webp --transparent

# Pick a different sequence
python index.py 4913.pet.json 4913._Atlas_.png -s attack --webp --transparent

# All options
python index.py -h
```

Always run from repo root — asset paths in the command are relative.

## WebGL preview

Open `index.html` directly in a browser (no server needed). It loads `./4913.pet.json` and `./4913._Atlas_.png` by default. The JS is inline — no build, no npm.

## Data files

- `*.pet.json` — Unity asset JSON (very large, ~190k lines). Contains `FrameRate` and a `Sequences` array of `{Name, Frames}`. Each frame has `MeshData.Vertices[{x,y}]` and `MeshData.UVs` (16.16 fixed-point encoding).
- `*._Atlas_.png` — texture atlas paired with the JSON.
- `img/` — README screenshots, not used at runtime.

## Output

Output goes to the directory specified by `-o` (default `output/`). The `output*` glob in `.gitignore` prevents accidental commits.

## Conventions

- No codegen, no migrations, no env files, no dev server.
- No tests exist — verify by running the tool and checking the output visually.
- The `.pet.json` files are too large for the Read tool — use `grep` to inspect them.
